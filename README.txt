# ShiftMaster Pro v1.1 — PWA

فایل اصلی برنامه: `index.html`

## اجرای آنلاین
این پوشه را روی هر سرویس میزبانی استاتیک (HTTPS) قرار دهید. سپس آدرس آن را با Chrome یا Safari آیفون باز کنید.

## نصب روی iPhone
در Safari:
Share → Add to Home Screen

پس از نصب، برنامه به شکل یک Web App اجرا می‌شود.

نکته: برای قابلیت‌های Excel، نسخه فعلی از کتابخانه XLSX از CDN استفاده می‌کند؛ بنابراین برای ورود/خروجی Excel اولین بار به اینترنت نیاز دارد.
